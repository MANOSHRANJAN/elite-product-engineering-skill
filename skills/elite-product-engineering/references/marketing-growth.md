# Marketing and Growth Reference

Use this for positioning, launch planning, acquisition, retention, monetization, content, landing pages, analytics, and growth experiments.

## Positioning

- Define the audience, painful job, current workaround, promised outcome, proof, and objection.
- Make the product category clear before clever copy.
- Lead with the concrete result users get, not the implementation technology.
- Match claims to product maturity. Do not overpromise unsupported AI, automation, revenue, or compliance outcomes.

## Funnel

- Map the current funnel: acquisition source, landing/store page, signup/install, activation, habit loop, monetization, referral.
- Find the biggest measured drop-off before proposing broad campaigns.
- If analytics are missing, implement the minimum event set before optimizing:
  - page/store view
  - signup/install
  - onboarding step completed
  - first value action
  - paywall/subscription viewed
  - purchase/trial started
  - retention event

## Launch

- Pick one primary audience and one primary channel for the first launch.
- Prepare landing/store copy, screenshots or demo video, onboarding, support path, analytics, and feedback capture.
- Launch with a specific offer or use case.
- Measure activation and retention before scaling paid acquisition.

## Experiments

- Write each experiment as hypothesis, audience, change, metric, duration, and decision rule.
- Prefer fast experiments with clear user behavior over vanity metrics.
- Use paid ads to test messaging before building expensive features when appropriate.
- Stop experiments that win clicks but hurt activation or retention.

## Monetization

- Align pricing with the value metric: seats, usage, outcomes, storage, automations, or premium capabilities.
- Make free limits teach the product's value without creating unsustainable cost.
- For AI products, protect gross margin with usage tiers, fair-use caps, cheaper model routing, and caching.
- Instrument trial start, activation during trial, conversion, cancellation, refund, and support reasons.
