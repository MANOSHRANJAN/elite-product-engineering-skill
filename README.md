# Elite Product Engineering Skill

A Codex skill for building, launching, marketing, and scaling software products with senior product engineering judgment.

It gives Codex focused workflows for:

- AI engineering: LLM features, agents, RAG, evals, cost, and latency
- SDE2 execution: implementation quality, debugging, code review, and tests
- Mobile and Play Store: app readiness, release process, policy-sensitive areas, and store growth
- Marketing and growth: positioning, funnel analytics, launch, experiments, and monetization
- Scaling systems: performance, reliability, observability, security, data, and cost control

## Install

Clone or download this repo, then run:

```bash
./install.sh
```

The installer copies the skill to:

```text
~/.codex/skills/elite-product-engineering
```

If `CODEX_HOME` is set, it installs to:

```text
$CODEX_HOME/skills/elite-product-engineering
```

## Use

Open any repo in Codex and ask:

```text
Use $elite-product-engineering to audit this repo and produce a high-impact execution plan.
```

Or:

```text
Use $elite-product-engineering to build, launch, market, and scale this app.
```

## Update

Pull the latest version of this repo, then rerun:

```bash
./install.sh
```

The installer replaces the existing installed copy.
